# Home of the MIT IEEE/ACM Club Website

This repository contains the source code for the official website of the MIT IEEE/ACM Club.

## Setting up the Dev Environment

Required tools:
- npm
- git

1. Clone and cd into git repository
```bash
git clone https://github.com/ieee-acm-mit/ieee-website
cd ieee-website
```

2. Install npm dependencies
```bash
npm install
```

3. Run development environment
```bash
npm run dev
```

As per Vite, the local site will be at http://localhost:5173.
